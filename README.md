# SEO/GEO Dashboard Data

Weekly SEO/GEO ranking data for [Hoojump.com](https://hoojump.com) (creator merch) and [Aivoxio.com](https://aivoxio.com) (AI voice agents).

## What This Repo Contains

- `seo_data_v2.json` — weekly SERP data: Google rankings, AI Overview citations, AI Mode citations, ChatGPT/Gemini visibility, People Also Ask, related searches, and competitor analysis
- `seo_data.json` — legacy v1 data

## Dashboard

Live dashboard: [fonzie-seo-dashboard.netlify.app](https://fonzie-seo-dashboard.netlify.app)

## Sites Tracked

| Site | Niche | Market |
|------|-------|--------|
| [Hoojump.com](https://hoojump.com) | Creator merch (POD) | USA + Canada |
| [Aivoxio.com](https://aivoxio.com) | AI voice agents | Ontario, Canada (bilingual EN/FR) |

## Data Collection

Powered by [SerpApi](https://serpapi.com) + OpenAI + Google Gemini. Runs weekly via Hermes Agent cron.
